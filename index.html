SeedVR2 Upscale

A Runpod Serverless worker that batch-upscales and restores videos and photos with official SeedVR2-3B (one-step diffusion, bfloat16) and returns files of the same type plus results.json.

GitHub Runpod Hub README

What you send / what you get

  • Send an image_url, a video_url, or a dataset_url zip of mixed media.
  • Get the same basenames back, plus a results.json manifest.
  • Default: SeedVR2-3B, one-step, bfloat16 autocast, res_h=720 / res_w=1280 area, sp_size=1.

Not the same as

  • SeedVR v1 — the multi-step official scripts are never called.
  • A ComfyUI port (tiling / FP8 / GGUF / BlockSwap are not mixed in).
  • Gradio or the official web Space — never started in this worker.

Example job

{
  "input": {
    "image_url": "https://example.com/photo.png",
    "model": "3b",
    "res_h": 720,
    "res_w": 1280
  }
}
